Python for Data Science: Week 3 Exercises

The following covers two Python programming exercises involving pandas and NumPy. Exercise 10 focuses on grouping and filtering sales data in a pandas DataFrame, while Exercise 11 demonstrates expanding a salary matrix using NumPy array operations.

Exercise 10: Excluding Total Rows from the DataFrame

Overview

The goal of this exercise was to merge sales data from multiple tables, compute total sales per order line, group the data by date and region, insert subtotal and grand total rows, and then exclude these summary rows for clean reporting.

Key Concepts

  • Merging DataFrames: Using merge() to join order, detail, employee, and location tables.
  • Calculations: Computing sales totals with Price * Quantity.
  • Aggregation: Grouping by Date and Region with groupby().sum().
  • Subtotals/Grand Totals: Inserting summary rows using pd.concat().
  • Filtering: Using MultiIndex slicing to exclude totals ('All' values).

Analysis of Results

The solution demonstrates effective use of pandas for multi-source data integration and aggregation. Excluding totals is essential for analysis accuracy. The use of MultiIndex slicing was clean and scalable. Improvements could include error checks for missing or malformed data.

Critique of AI

Prompt used "Generate Python code to process sales data by merging DataFrames, aggregating totals, adding subtotal/grand total rows, and excluding them with pandas MultiIndex slicing"

The result merged and aggregated DataFrames, calculated totals, added summary rows using pd.concat(), and filtered them out with MultiIndex slicing. The final output was accurate; it initially used the deprecated .append() method and lacked inline comments and data validation. The prompt was clear but could be improved by requesting modern practices, explanatory comments, and error handling. Overall, the solution was effective but would benefit from better documentation and adherence to current standards.

Exercise 11: Adding New Rows/Columns to a NumPy Array

Overview

This task involved expanding the 2D salary matrix by adding more months (columns) and new employees (rows), reflecting changes over time using NumPy functions.

Key Concepts

  • Adding Columns: Using np.concatenate() and np.column_stack() to add new monthly salary data.
  • Adding Rows: Using np.append() to introduce new employees.
  • Salary Adjustment: Simulating 5% raises for new months.

Analysis of Results

The result, a 6×6 salary matrix, demonstrates correct use of vectorized operations for time-based expansion. Rounding floating-point results could enhance realism. The approach scales well and mirrors real HR/payroll scenarios.

Critique of AI

Prompt used “Extend a NumPy array of salaries with two new columns and one new row using np.concatenate() and np.append()."

The result used NumPy to create a salary array and successfully built a 6×6 matrix with simulated raises by using functions like concatenate(), column_stack(), and append(). Initially, forgetting to include the axis parameter in append() led to a shape error, but this was fixed later. While the floating-point results were accurate, they weren't rounded, which makes them less practical for real-world use. The prompt could be clearer by specifying the expected shape of the array, the type of data needed, and steps for checking the results.
