Python for Data Science: Week 2 Exercises

The following goes over the implantation and analysis of the Python script found in the WK2_SCoggeshall.py file.

Exercise 5: Opening JSON Files

Implementation

This exercise requires reading and writing JSON files in Python. The json module serializes a dictionary of car data into a JSON file and then deserializes it back into a Python object. The extracted data is displayed in a structured format (Json — JSON Encoder and Decoder, n.d.).

Analysis of Results

The script stored and retrieved structured data in JSON format. The formatted output provided a structured and readable display of car details.

Exercise 6: Accessing an API with Requests

Implementation

A GET request is sent to NewsAPI using the requests library to retrieve news articles about Python programming (Documentation - News API, n.d.). The response is parsed to extract and display article titles, publication dates, and URLs.

Analysis of Results

The API call returned relevant articles about Python programming. Using requests.get() provided a simple way to retrieve and parse JSON responses from APIs efficiently.

Exercise 7: Manipulating Complex JSON Structures

Implementation

Nested JSON data is converted into a pandas DataFrame, normalized, grouped, and reconstructed back into its original JSON structure and keeps data relationships.

Analysis of Results

The transformation allowed efficient analysis of nested JSON data using pandas, keeping data integrity through normalization and restructuring.

Exercise 8: Performing a One-to-Many Join

Implementation

A relational database join is executed in MySQL, linking employees (emps) to orders (orders). The query retrieves order numbers, employee names, and order totals for employees with an empno greater than 9001.

Analysis of Results

The join operation retrieved employee order details, using SQL to manage relationships between tables and keep data accuracy in relational databases.

Exercise 9: Inserting and Querying Multiple Documents

Implementation

Bulk insertions and document retrieval are performed using MongoDB and PyMongo. Employee records are stored with embedded order details, and queries are executed to fetch all employee documents from the collection.

Analysis of Results

MongoDB’s flexibility allowed efficient storage and retrieval of employee records, demonstrating NoSQL’s ability to handle hierarchical data structures and its scalability for large datasets.

Critique of AI Tools Used

AI tools can be difficult to use when using API keys and local database files. I try not to upload any API keys or passwords into prompts or scripts. I use place holders to keep that information private. AI tools accelerated development but required human revision for correctness and best practices.
