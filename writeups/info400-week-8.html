Week 8 Project: Florida Housing Price Analysis and Prediction

This project analyzes historical Zillow Home Value Index (ZHVI) trends for single-family homes in all Florida counties, with focused attention on Duval County (Jacksonville) and St. Johns County, FL, from 2018 to 2023. It uses a linear regression model to forecast future home values based on historical trends.

Objective and Scope

The primary objective is to visualize historical home value trends and develop a simple but effective prediction model based on past ZHVI values. The analysis covers monthly ZHVI data from 2018–2023 for single-family homes across Florida counties, specifically highlighting Duval and St. Johns counties.

Dataset and Problem

The dataset, obtained from Zillow Research (fl.csv), contains county-level monthly ZHVI values. The core task is predicting future ZHVI values based on recent historical trends.

Approach

The project involves visualizing monthly trends with line charts and employing linear regression using the past 12 months' home values to predict the next year’s ZHVI.

Data Description

  • The dataset includes three main features:
  • Date (datetime): monthly measurement date
  • RegionName (string): county names
  • ZHVI (float): Zillow Home Value Index values

Data Visualization Report

Visualizations created as line charts reveal clear trends over the five-year period. Duval County displayed steady growth with a notable peak around 2021–2022. St. Johns County consistently maintained higher home values but exhibited more volatility, surpassing $500,000 at its peak. The visualizations provided comparative insights, highlighting differing trends and volatility between counties. (Charts saved in ./output/ directory.)

Data Prediction Report

A linear regression model was selected due to its simplicity, interpretability, and effectiveness in capturing linear historical trends using the previous 12 months of ZHVI data.

Implementation Details

The project was implemented in Python 3 using pandas, numpy, matplotlib, seaborn, and scikit-learn. It can run in any standard Python environment or Jupyter Notebook on standard hardware without the need for specialized resources.

Conclusion & Recommendations

The analysis revealed distinct trends and variability between counties. Linear regression offered reliable forecasts for steadily growing counties, but performance varied in more volatile areas. ZHVI historical trends serve as useful indicators for forecasting in stable markets.

Future analyses could benefit from incorporating macroeconomic factors like mortgage rates, employment data, and demographics. Exploring advanced time series models, such as ARIMA or machine learning, may enhance accuracy.
