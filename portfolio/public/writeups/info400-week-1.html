Exercise 1: Improved Photo Tag Analysis

Problem Description

This exercise involves categorizing images based on shared metadata tags. Given a set of images with associated descriptive tags, the objective is to identify and organize photos with common characteristics using sets and dictionaries.

Solution Approach

  • The script iterates through all pairs of images to identify shared tags.
  • A dictionary stores grouped images under keys formed by intersecting tags.
  • The setdefault() method checks that only relevant image pairs are added without redundancy.

Results and Analysis

The script categorized images based on shared tags for a metadata classification. This method is used in image classification, metadata organization, and content-based image retrieval. Using sets for tag comparison improves lookup speed and minimizes redundant operations (Vasiliev, 2022).

Exercise 2: Using NumPy Statistical Functions

Problem Description

This uses NumPy’s numerical for processing employee salary and bonus data. The script calculates:

  • Total salaries (base salary + bonus).
  • Maximum salary per month.
  • Highest recorded salary.
  • Average of max salaries per month.

Solution Approach

  • Uses NumPy arrays for efficient numerical processing.
  • Performs calculations using built-in NumPy functions such as amax and average.

Results and Analysis

NumPy simplifies array operations, making salary computations more efficient. This enhances payroll management, financial forecasting, and statistical data analysis. NumPy's optimized array operations outperform traditional list-based computations (NumPy quickstart, n.d.).

Exercise 3: Combining Three Series

Problem Description

This exercise focuses on merging three Pandas Series representing employee names, emails, and phone numbers into a single structured DataFrame.

Solution Approach

  • Creates three separate Pandas Series for names, emails, and phone numbers.
  • Uses the concat() function to merge these Series into a single DataFrame.

Results and Analysis

The final DataFrame consolidates multiple employee attributes, making data retrieval more structured and efficient. This method is useful for HR databases, CRM systems, and structured contact management. Using Pandas for data merging simplifies relational data handling.

Exercise 4: Using Different Joins

Problem Description

This exercise uses merging datasets (employee details and salaries) using inner and outer joins in Pandas.

Solution Approach

  • Loads employee and salary data into Pandas DataFrames.
  • Performs inner joins (including only matching records) and outer joins (preserving unmatched records).
  • Uses concat() instead of the deprecated .append() method for efficiency.

Results and Analysis

The script merged datasets, demonstrating how different join operations influence data integration.

  • Inner joins retain only matching records between datasets.
  • Outer joins preserve all records, even those missing corresponding salary or job details.

This exercise shows Pandas' usefulness in managing structured datasets, making it best for HR databases, payroll processing, and ERP systems.
