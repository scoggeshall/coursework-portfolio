Exercise 18: Mining Real Transaction Data Overview

This exercise involved extracting insights from transactional data by identifying frequent item sets and generating association rules. Using Python libraries including pandas, numpy, and mlxtend, the dataset was cleaned, encoded into a suitable format, and analyzed to discover item relationships.

Key Concepts

  • Removed entries missing item descriptions and grouped transactions by invoice.
  • Transformed transaction data into a one-hot encoded format using TransactionEncoder.
  • Identified frequent itemsets using the Apriori algorithm (min. support: 2.5%).
  • Generated association rules (min. confidence: 30%), evaluated by confidence and lift metrics.

Analysis of Results

The script The analysis identified 136 frequent itemsets, with "WHITE HANGING HEART T-LIGHT HOLDER" being most common (9.4%). Strong product associations included:
