Python for Data Science: Week 7 Exercise

Exercise 19: Expanding the Example Set

This exercise addressed class imbalance in a sentiment‐classification task using the “Amazon Product Reviews” dataset (Amazon product Reviews, 2021). We sampled 500 reviews per star rating (1–5) with replacement as needed, vectorized titles via Bag‑of‑Words, and trained a logistic regression model to predict ratings.

Key Concepts

  • Class balance: Stratified sampling to give each rating equal representation (Vasiliev et al., 2022).
  • Text vectorization: Converting titles into numeric features with CountVectorizer.
  • Logistic regression: Supervised classification of discrete labels.

Analysis of Results

The model reached 45 percent accuracy. Five‑star reviews had the highest recall (57 percent); mid‑range ratings (2–4) fell between 35 and 44 percent recall. The confusion matrix showed frequent misclassification among adjacent ratings, highlighting BoW + logistic regression limitations for nuanced text.

Critique of AI

Prompt used " Generate Python code to balance an Amazon reviews dataset and train a logistic regression model using scikit‑learn. “

While the AI‐generated code outlined the workflow, it lacked error handling for missing text, cross‑validation, TF‑IDF exploration, and hyperparameter tuning.

Exercise 20: Experimenting with Different Stocks and New Metrics

This exercise extended stock‑trend classification by adding technical indicators and applying the model to various tickers. Using one year of daily data for AAPL and the S&P 500, we engineered seven features—price and volume log‑returns, index returns, intraday volatility, 5‑day momentum, and 14‑day RSI—and trained a balanced logistic regression to predict next‑day movement (“Up,” “Down,” “Flat”).

Key Concepts

  • Time‑series feature engineering: Log‑returns, momentum, volatility, and RSI to capture market behavior (Vasiliev et al., 2022).
  • Multi‑class classification: Three‑way prediction of price movements.
  • Class weighting: Using class_weight='balanced' to mitigate target imbalance.

Analysis of Results

For AAPL, accuracy was 39.6 percent. The “Flat” class was poorly predicted, and “Up” versus “Down” often confused the model. This suggests linear models may underperform on noisy financial data and that richer features or more complex algorithms (e.g., treebased) are needed.

Critique of AI

“Generate Python code to predict next‑day stock movements using technical indicators and logistic regression with balanced classes.”

The AI solution enhanced the example by adding new indicators but omitted crossvalidation, hyperparameter tuning, model comparison, and featureimportance visualization.
