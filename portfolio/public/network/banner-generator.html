Cisco ASCII Banner Generator

Generate predictable terminal-safe banner text with explicit layout constraints.

  • Python
  • pyfiglet
  • CLI
  • ASCII

Purpose

Produce readable, terminal-safe ASCII banner text with consistent spacing and an explicit width budget. The tool generates text; it does not connect to network devices.

Implementation

The Python CLI uses pyfiglet glyphs, normalizes their visible bounds, and composes words with predictable spacing. Automatic layout tries the approved fonts, wraps at word boundaries, and centers logical blocks.

Features verified in source

Printable-ASCII validation, width checks, delimiter selection, safe output filenames, single-file output, batch generation, and preview diagnostics are implemented. Explicit font selection preserves the caller’s choice rather than silently substituting a font.

Technical challenges

Visible glyph spacing differs from raw character-cell padding. Banner delimiters must not collide with generated content, and batch filenames must avoid reserved names and collisions.

Limitations

The README declares Python 3.14+ and pyfiglet 1.0.4. Output still needs review for the target platform and local policy. Existing output files can be overwritten. No device deployment or fresh rendering test is claimed.
