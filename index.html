Florida Housing Analysis And Prediction

INFO400

Loads Zillow Home Value Index data for every Florida county, reshapes the wide monthly columns into a tidy time series, and filters to 2018–2023. For each county it builds twelve monthly lag features, trains a linear regression model, and scores actual versus predicted home values.

Output is a per-county set of trend plots, actual-vs-predicted charts, and evaluation metrics. Counties with fewer than 24 observations are skipped rather than trained on insufficient data.

  • pandas
  • NumPy
  • scikit-learn
  • seaborn
  • matplotlib

ENTD320

Week 1 is a Flask app that returns a greeting. By week 7 the same calculator has become two independent services — a JSON arithmetic API and a second service — sharing one SQLite database and writing every calculation to a common history table.

Along the way: an encapsulated Use_Calculator class with private methods, RESTful URL routes, Jinja2 templates with form handling, database persistence with a history page, and a unittest suite covering every operation.
