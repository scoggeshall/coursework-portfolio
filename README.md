# Coursework Portfolio — Sean Coggeshall

Information Technology coursework from American Public University System, across an
Associate's and a Bachelor's degree, presented as a static portfolio site.

The site lives at the repository root (`index.html`, `styles.css`, `script.js`)
and every course sits beside it in its own folder. That layout is deliberate:
because the front-end assignments are served from the same GitHub Pages site,
they run as live demos instead of being described in prose.

## Publishing to GitHub Pages

1. Create the repository on GitHub and push this folder.
2. In **Settings → Pages**, set the source to the `main` branch, root folder.
3. Open `script.js` and set `REPO_BASE` to
   `https://github.com/<user>/<repo>/blob/main/` — every "View source" and
   "Files" link then points at GitHub rather than the raw file.

`.nojekyll` is present so Pages serves folders beginning with an underscore
and skips Jekyll processing entirely.

## What is and is not committed

The course folders were copied from local `Associates/` and `Bachelors/`
directories that also contain material that is not Sean's own work — publisher
slide decks, textbook chapters, journal article PDFs, lecture audio, graded
report cards, and syllabi. `.gitignore` keeps all of that local.

That exclusion is not only about copyright. The raw folders total roughly
1.6 GB, and five individual files exceed GitHub's hard 100 MB per-file limit,
which would cause an outright push rejection. What remains tracked is about
107 MB of authored work, with no file over 50 MB.

If you add a new course folder, check what came with it before committing.

## Layout

```
index.html / styles.css / script.js   the portfolio site
<Course-Name-CODE>/                   one folder per course
```

Course folders are named `Title-Case-With-Hyphens-COURSECODE`, dropping the
code where the course did not have one on disk.

## Course-level index pages

`User-Interface-Design-WEBD300/index.html` is a hand-written index linking the
Coggs Web Craft landing page and all nine responsive template variants, so the
course gets one entry point on the portfolio rather than four separate links.

## Folder index pages

Every publishable folder carries an `index.html`, generated by
`.claude/generate_folder_indexes.py`, so a bare folder URL lands on a short
page pointing back at the portfolio rather than a raw file listing. A root
`404.html` catches anything else. Re-run it after adding a course folder:

```bash
python .claude/generate_folder_indexes.py
```

Worth being clear about the limits: these pages stop a *listing*, not access.
Any committed file stays reachable at its own URL. `.gitignore` is the only
thing that decides what gets published.

## Write-ups

`writeups/` holds 19 assignment reports, papers, and presentations rendered as
web pages from the original `.docx` / `.pptx` files, linked from the course
cards that have them. They are generated by `.claude/extract_writeups.py`,
which reads the untouched `Associates/` and `Bachelors/` trees and writes into
`writeups/`. Re-run it after adding coursework:

```bash
python .claude/extract_writeups.py
```

It extracts only documents containing "Coggeshall" — the course folders are
full of instructor handouts, lecture transcripts, and publisher tutorials that
must not be republished. It also strips APA title blocks (author, university,
instructor name, submission date), Word table-of-contents entries, and field
codes. The generator lives in the gitignored `.claude/` folder because it reads
paths outside the repo; only its output is committed, so the site itself still
has no build step.

## Editing the site

Course cards and demo links are data, not markup — both live in arrays at the
top of `script.js` (`DEMOS` and `COURSES`). Adding a course means adding one
object; nothing in `index.html` needs to change. The seven featured projects
are static markup in `index.html`.

A handful of Associate's courses were filed by course code only, so their cards
use the code as the title. Those are marked with a note in `script.js` — drop
the official titles in from the degree plan when convenient.

## Local preview

```bash
python -m http.server 4173
```

Then open <http://localhost:4173>. Opening `index.html` directly from disk also
works, though some browsers restrict `file://` requests.
